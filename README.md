# Paradise Nursery Shopping Application (e-plantShopping)

Paradise Nursery is a React and Redux e-commerce web application for browsing and purchasing houseplants across multiple categories.

## Features

- Interactive landing page with company overview and quick navigation.
- Categorized plant catalog with dynamic "Add to Cart" state management.
- Real-time cart badge counter in navigation bar.
- Full shopping cart functionality: item subtotal calculation, total cart amount, quantity increment/decrement, and item removal.
